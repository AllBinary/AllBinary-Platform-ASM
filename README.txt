                             AllBinary Platform ASM

What is it?

This repository contains code generated by the AllBinary Platform for support in ASM.  
This repo is used to allow developers to skip the ASM code generation step.

What are some example games with this ASM code?

https://allbinary.itch.io (The downloads with "-asm" in the filename are ASM only builds. Currently that only includes nothing. Also the ASM builds are not available on Google Play or other stores.)
